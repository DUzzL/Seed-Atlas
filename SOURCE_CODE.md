# Corresponding source code

The complete corresponding source code of every published Seed Atlas build is
provided as `Seed-Atlas-<version>-Source.zip` (for example
`Seed-Atlas-4.3.dev0-Source.zip`), where `<version>` is the version shown in
the About dialog and stored in `VERSION.txt`.

The archive is attached to the GitHub release of the build
(https://github.com/DUzzL/Seed-Atlas/releases), is included in the Windows
installation under `Source`, and is also distributed alongside the Windows
installer. It contains the application source, the generation engine, the mod
interface (`seedatlas-sax`), bundled libraries, resources, project files, the
tools that generate the GPU kernels, build instructions, and the installer
scripts needed to reproduce and modify the build. The macOS and Linux packages
are built from the same source.
